CASEIRINHOS DO JU — V8 PREÇOS FÁCEIS

1) PARA ALTERAR PREÇOS PELO CELULAR
   Abra no GitHub:
   data/precos.json

   Altere apenas os números e faça Commit changes.
   O GitHub Actions atualiza automaticamente o catálogo e as páginas dos produtos.

2) PARA EDITAR NOMES, TEXTOS OU IMAGENS DOS PRODUTOS
   data/catalog.json

3) PARA TESTAR LOCALMENTE
   python server.py
   Abra http://localhost:5000

4) PARA TROCAR IMAGENS
   assets/images/

5) GITHUB PAGES
   Envie todo o conteúdo desta pasta para a raiz do repositório.
   Em Settings > Pages, use GitHub Actions como Source.
