CASEIRINHOS DO JU — V7 ULTRA

1) Para testar localmente:
   python server.py
   Abra http://localhost:8000

2) Para editar produtos e preços:
   data/catalog.json
   Depois rode: python scripts/build_catalog.py

3) Para trocar imagens:
   assets/images/

4) Camada visual principal:
   assets/css/style.css
   assets/css/vfx.css

5) Interações:
   assets/js/app.js
   assets/js/vfx.js

6) GitHub Pages:
   suba todos os arquivos na raiz do repositório.
   O workflow .github/workflows/pages.yml faz validação, build e deploy.

A assinatura TAJO Digital 3F fica somente no cabeçalho do site.
